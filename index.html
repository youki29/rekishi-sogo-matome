ヴェルサイユ体制とワシントン体制

教科書 p.94–97

WWⅠ後、新たにどのような国際体制が築かれたのだろう？

ヴェルサイユ体制（ヨーロッパ／ドイツ封じ）

  • 1919年 パリ講和会議：ウィルソンの十四か条の影響のもと戦勝国で話し合い
  • 中心：アメリカ（ウィルソン）、イギリス（ロイド＝ジョージ）、フランス（クレマンソー＝ドイツを厳しく罰したい）。イタリア（オルランド）、日本（西園寺公望）も参加
  • 対独講和条約＝ヴェルサイユ条約に基づきヴェルサイユ体制が成立
ヴェルサイユ条約の内容（テストで◯×で出るかも）
  • アルザス・ロレーヌをフランスに割譲（鉄・石炭の産地）
  • ラインラントの非武装化（ライン川のまわり）
  • 軍備の一部禁止（軍備制限）
  • 多額の賠償金支払いの義務（GNPの約20年分＝支払い不可能）
  • すべての植民地の没収
  • 日本が国際連盟の委任統治領として旧ドイツ領の南洋諸島を支配
→多くのドイツ人が不満 → のちのヒトラー登場へ

国際連盟（1920年発足）

  • 目的：国際平和の維持と国際協力の促進。本部はジュネーヴ
  • アメリカの不参加（大統領が提案したのに、議会が孤立主義で反対）
  • 当初は敗戦国ドイツと社会主義のソ連を除外（ドイツは1925年ロカルノ条約に基づき翌1926年加盟）
  • 議決方法：全会一致／制裁措置：経済制裁が中心

民族自決とその限界

民族自決とは：各民族が自分たちの政治体制を、他国から干渉されずに決められるという考え
  • 民族自決が適用されたのは東ヨーロッパやバルカン半島だけ → 戦勝国は、独立国がソ連（社会主義）に対する壁になることを期待
  • アジアやアフリカには適用されず → 朝鮮で三・一独立運動、中国で五・四運動
ヴェルサイユ体制の問題点
  1. ドイツにとって懲罰的で過酷すぎる内容
  2. 民族自決の原則はアジアやアフリカには適用されず
  3. アメリカの不参加、当初はソ連や敗戦国ドイツを除外
  4. イギリス・フランスの意向が反映されてバランスを欠く

ワシントン体制（アジア・太平洋／日本封じ）

  • 1921年 ワシントン会議：アメリカ大統領ハーディングの提唱。英・日・仏などが参加
条約内容
四か国条約（1921）太平洋の安全保障、日英同盟の破棄
九か国条約（1922）中国の門戸開放・機会均等を確認。日本は中国に山東省の旧ドイツ権益を返還（二十一か条要求の一部がなくなる）
海軍軍備制限条約（1922）主力艦の保有制限　英：米：日：仏：伊＝5：5：3：1.67：1.67

→ 台頭した日本を抑え込む体制。日本のメディアは「アメリカなどの要求で日本が多くの権益を失った」と受け止めた。

なぜ日本は受け入れた？
大戦景気が終わり財政難。全権の加藤友三郎は「金がなければ戦争ができぬ」と述べ、軍縮のほうが安全保障上合理的と判断。欧米と協調して孤立を避けたかった。

国際協調・軍縮の動き

  • ヴェルサイユ体制とワシントン体制のもとで国際協調の機運が高まる
  • 1928年 不戦条約（パリ）：国際紛争を解決する手段として戦争を用いることは違法
  • ただし自衛のための戦争は認められた → ヒトラー（WWⅡ）を止められなかった

アジアのナショナリズム

教科書 p.102–104

WWⅠ後、アジアのナショナリズムはなぜ高まったのだろう？

ナショナリズム＝国民主義・民族主義（愛国心）。

朝鮮

  • 1910年 韓国併合 → 朝鮮総督府を設置し、武断政治（軍人が厳しく支配）を行う。初代総督は寺内正毅（伊藤博文は前年に暗殺された）
  • 1919年 三・一独立運動：日本の支配に対して「独立万歳」を叫んだ民衆の運動
  • きっかけの「新しい考え」＝ウィルソンの民族自決
  • 女性たちは武器を持たずに行進 → 武器ではなく非暴力の抗議で国際社会の支持を得ようとした

中国

  • 1915年 日本が二十一か条の要求を突きつけ、山東半島のドイツ権益を得る
  • 1919年 パリ講和会議（ヴェルサイユ条約）で、要求の取り消しと山東半島の権益返還を求めるが認められず
  • 1919年 五・四運動：北京大学の学生を中心にデモ
  • 1921〜22年 ワシントン会議（九か国条約）で山東の権益が中国に返還される（日本封じ）

インド

  • WWⅠ前：日露戦争での日本の勝利に刺激をうけ、民族的自覚と反英意識が高まる
  • 大戦中、イギリスはインドに戦争協力の代わりに自治を約束 → 守らなかった
  • 1919年 ローラット法：令状なしの逮捕や裁判なしの投獄を認める
  • ガンディーによる非暴力・不服従の運動
  • 1930年 塩の行進：約360kmを行進し、自分たちで塩を作る（イギリスの塩の専売への抗議）
ガンディーと糸車
若い頃は西洋風のエリートの服装 → のちに手織りの布をまとい、糸車（綿花から糸をつむぐ）を使った。インドの国旗案にも糸車。
産業革命でイギリスの綿製品がインドに流れ込み、インドの手織り職人は失業、インドは綿花を輸出するだけのモノカルチャー化。
→ 西洋の近代文明を否定し、インドの伝統に基づいた産業の復興と国産品愛用を主張。誰でも参加しやすく、民衆に広く受け入れられた民族運動。

西アジア

大戦中のイギリスの多重外交や、オスマン帝国に対する不平等条約などがナショナリズムの高まりにつながった。

まとめ
中国ではパリ講和会議で山東半島の権益の返還が認められなかったことが、朝鮮ではウィルソン大統領の民族自決の影響を受けたことが、ナショナリズムの高まりにつながった。インドでは大戦中に約束された自治が守られなかったこと、西アジアでも大戦中のイギリスの多重外交やオスマン帝国に対する不平等条約などが、ナショナリズムの高まりにつながった。

アメリカの繁栄とその陰

教科書 p.88〜

WWⅠはアメリカにどのような影響を与えたのだろう？

アメリカの繁栄

  • 背景：WWⅠの被害が軽微／ヨーロッパに軍需物資や戦費を提供し、経済的地位を向上
  • WWⅠ後、債務国から債権国へ転じ（借りる側 → 貸す側）、世界経済の中心へ
  • フォード社のベルトコンベア方式で自動車産業が栄え、ラジオ・映画などメディアも発達、庶民の生活が豊かに
  • 1920年代、都市を中心に大量生産・大量消費をもとにした大衆文化が形成された（大衆消費社会）

繁栄の陰：社会の不寛容さ・保守化

  • アメリカの中心＝WASP（White Anglo-Saxon Protestant）
  • ストッダード『白人世界の優位に対抗する有色人種の勃興』（1920年）：白人の世界支配が揺らぐという不安 → アジアからの移民への人種差別
  • 移民法（1924年）で日本人などを排斥（人口増加・文化の違い・現地の人が失業するという反発）
  • KKK（クー・クラックス・クラン）による黒人迫害
  • 禁酒法：ビール醸造の多いドイツ系への迫害の面も。密造酒が出回りマフィアが台頭、代替飲料が流行

世界恐慌の時代

教科書 p.116–119

世界恐慌はなぜ波及し、それに各国はどのように対応したのだろう？

恐慌前のお金の流れ

  • 1924年 ドーズ案：賠償金の支払い期限の緩和と、アメリカ資本のドイツへの貸与
  • アメリカ →（融資）→ ドイツ →（賠償金：ヴェルサイユ条約）→ 英・仏・伊 →（戦債支払い）→ アメリカ
  • 最も重要なのはアメリカからドイツへの融資。国際経済はアメリカによって動いていた

恐慌の発生と波及

  • 1929年 ニューヨーク株式市場（ウォール街）で株価が大暴落し、世界恐慌が始まる
  • 原因：戦後の過剰な工場生産や行き過ぎた投機など（作りすぎた → 余った → 値下がり）
  • 多くの国で銀行の倒産や工場の閉鎖が相次ぎ、大量の失業者が生まれる
  • アメリカの資本が各国から引き上げられ、全資本主義国へ波及
  • 失業率グラフ：A＝ドイツ（30%超）、B＝アメリカ、C＝日本

アメリカの対応

  • 1931年 フーヴァー＝モラトリアム：賠償金・戦債支払いの1年間の支払い猶予 → 効果なし
  • フランクリン＝ローズヴェルト大統領のニューディール政策（恐慌打開政策の総称）
年政策内容
1933農業調整法（AAA）政府が農業生産や価格を調整（作りすぎ対策）
1933全国産業復興法（NIRA）政府が企業の生産を統制
1933テネシー川流域開発公社（TVA）ダム建設などの公共事業による失業者対策
1935ワグナー法団結権・団体交渉権の容認

AAAとNIRAの共通点：政府が民間の経済活動に介入（資本主義なのに自由を制限＝修正資本主義）。しかし両法は最高裁で憲法違反となり、目立った成果は出せず…。

各国の対応

  • 1914年の植民地面積：A＝イギリス、B＝フランス、C＝ドイツ、D＝日本
  • 「持てる国」（英・仏）：植民地を使ったブロック経済 … 連邦内では関税を引き下げ、連邦外には高関税（保護貿易）
  • 「持たざる国」（日・独・伊）：侵略によって市場・領土の拡大を図る＝ヴェルサイユ体制・ワシントン体制の打破を目指す
    • 日本：軍部（関東軍）の台頭、1931〜33年 満洲事変 → 満洲国の建国
    • イタリア：ムッソリーニによる独裁（1922–1943）
    • ドイツ：ヒトラーによる独裁（1933–1945）
  • 日独伊の国際的孤立が強まる → 1939年 第二次世界大戦へ
まとめ
第一次世界大戦後、世界経済の中心はアメリカであった。そのニューヨークで株価の暴落から始まった恐慌は、ヨーロッパに投資していた資金の回収や市場の縮小により世界に波及した。英仏はブロック経済による保護貿易などによって恐慌からの脱出を図ったが、それまでの世界経済の繁栄の前提であった自由貿易の機会は失われ、社会は不安定化していった。ブロック経済は第二次世界大戦の遠因となる…。

ファシズムの伸長と共産主義①

教科書 p.120〜

ナチスの2つの大罪
  1. ホロコースト：反ユダヤ主義を掲げ、ユダヤ人を大虐殺（約600万人の犠牲者）
  2. 断種法、T4作戦（障害者などの殺害、7万273人の犠牲者）

ヒトラーが大衆の支持を得たのは、なぜだろう？

  • ヒトラー（独）とムッソリーニ（伊）の共通点：大勢の人の前で演説し国民の支持を得た独裁者。軍服姿（暴力的）
  • ⇒ 独裁者は民主主義の中から誕生した！

ドイツ年表

1919ヴェルサイユ条約：ドイツに対する懲罰的な内容（賠償金が多い、植民地取り上げ）→ ドイツ不景気・国民の不満
1919ヴァイマル憲法：世界で最も民主的な憲法と言われる（社会権・生存権）。ヴァイマル共和国（1918–1933）
1920国民社会主義ドイツ労働者党（ナチ党）の結成：党首アドルフ＝ヒトラー
1923ミュンヘン一揆に失敗し投獄。獄中で『わが闘争』を口述筆記
1929世界恐慌 → ナチ党は方針転換（暴力ではなく選挙で）
1930総選挙で第2党に躍進（合法的）
1932総選挙で第1党に躍進
19331月 ヒトラー内閣誕生
2月 国会議事堂放火事件を口実に共産党を弾圧
3月 全権委任法 → 一党独裁体制を確立
10月 国際連盟の脱退
1934総統（フューラー）になる（首相＋大統領）
1936ラインラント進駐などヴェルサイユ体制を無視して膨張を続ける
1939第二次世界大戦の勃発
全権委任法の何が問題？
立法権を内閣に委任したこと。モンテスキューが『法の精神』で説いた三権分立（立法＝国会、司法＝裁判所、行政＝内閣）が崩れ、内閣が法律を自由に作れるようになった。
共産党とは：社会主義、平等を重視、ソ連を目指す、団結・革命 → ナチスは反共産主義

ナチ党のスローガン

  • ヴェルサイユ体制の打破
  • ドイツ民族の優位性とユダヤ人排斥
  • 反共産主義
  • 失業者の救済
  • 領土の拡大
